# Scripts SQL anteriores a Flyway

Esta carpeta es solo referencia histórica. **No se ejecuta** ni la usa la aplicación.

La fuente de verdad del esquema son las migraciones de Flyway en
`backend/src/main/resources/db/migration`, y los datos de demostración están en
`backend/src/main/resources/db/dev`. Ejecutar estos scripts a mano sobre una base
creada con Flyway puede duplicar o romper estructuras.
